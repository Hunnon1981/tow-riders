┌──────────────────────────────────────────────────────────────────────────────┐
│ 🚀 QUICK START                                                                │
└──────────────────────────────────────────────────────────────────────────────┘

1. Install Dependencies
   $ cd backend
   $ npm install

2. Setup Database
   $ createdb express_tow_db

3. Configure Environment
   $ cp .env.example .env
   # Edit DATABASE_URL and JWT secrets

4. Setup & Seed Database
   $ npm run prisma:generate
   $ npm run prisma:migrate
   $ npm run prisma:seed

5. Start Server
   $ npm run dev

Server: http://localhost:5000
Health: http://localhost:5000/health
API:    http://localhost:5000/api/v1

const response = await fetch('http://localhost:5000/api/v1/bookings', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify(bookingData),
});

const result = await response.json();
if (result.success) {
  window.location.href = `booking-confirmation.html?id=${result.data.booking.id}`;
}

Update admin pages to fetch from API:

const token = localStorage.getItem('token');
const response = await fetch('http://localhost:5000/api/v1/bookings', {
  headers: { 'Authorization': `Bearer ${token}` },
});

const result = await response.json();
displayBookings(result.data.bookings);
